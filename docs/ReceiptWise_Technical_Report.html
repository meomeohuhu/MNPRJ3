3. Technical Architecture & Project Structure

Ứng dụng tách presentation, model, service, repository và provider. ExpenseProvider dùng ChangeNotifier điều phối trạng thái và refresh sau CRUD. DatabaseService quản lý SQLite version 1; FileStorageService lưu ảnh/thumbnails trong application documents. OcrService chỉ phụ trách ML Kit; ReceiptParserService là pure Dart để test độc lập; AggregationService gom dữ liệu theo tuần, tháng và danh mục.

lib/ ├── app/ # Material 3 theme và app shell ├── core/ # constants, formatters, reusable widgets ├── models/ # Expense, receipt parse result ├── features/ # home, scanner, expenses, history, analytics ├── services/ # OCR, parser, database, storage, aggregation ├── repositories/ # SQLite repository ├── providers/ # ExpenseProvider / ChangeNotifier └── main.dart

Luồng xử lý chính

Camera/Gallery → Crop thật → OcrService → ReceiptParserService → ReceiptReviewScreen → ExpenseProvider → SQLite + application documents → Dashboard/History/Analytics.

Offline OCR và receipt parser

  • ML Kit chạy on-device, không Firebase, không cloud API, không yêu cầu internet sau khi model thiết bị sẵn sàng.
  • Chuẩn hóa Unicode/whitespace và dấu tiếng Việt trước khi phân tích.
  • Nhận các nhãn: TỔNG, TỔNG CỘNG, TỔNG THANH TOÁN, TỔNG TIỀN, THÀNH TIỀN, TOTAL, AMOUNT DUE.
  • Hỗ trợ `150.000đ`, `150,000 VND`, `150 000 VNĐ`, `1,300,000`; loại trừ VAT, giảm giá, tiền thừa và tổng số lượng.
  • Nếu OCR tách nhãn và số tiền thành hai dòng hoặc độ tin cậy thấp, parser vẫn điền candidate và đánh dấu trường cần người dùng kiểm tra.
